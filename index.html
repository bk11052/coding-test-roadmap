삼성형 구현 체크포인트

  • 상태 변수를 먼저 정리합니다. 위치, 방향, 남은 횟수 등
  • 지문의 처리 순서를 번호 매겨 적고, 그 순서대로 함수를 나눕니다
  • "동시에"라는 말이 나오면 임시 배열에 모아 한 번에 반영합니다
  • 방향 배열 dy, dx와 범위 체크는 외워 둡니다
  • 90도 회전: b[j][n-1-i] = a[i][j]
  • 반례는 입력 범위의 양 끝값으로 먼저 시험합니다

카카오·네이버형 체크포인트

  • 문자열 split, 정규식, 시간 문자열 변환을 손에 익힙니다
  • 해시맵으로 집계하고, 정렬 기준을 여러 개 쓰는 연습을 합니다
  • 정확성과 효율성 채점이 따로 있으면, 효율성이 안 되더라도 정확성 점수부터 챙깁니다
  • 앞 번호일수록 쉬운 경향이 있으니 앞 번호부터 순서대로 풀되, 막히면 넘어갑니다
  • SQL은 GROUP BY, JOIN, 서브쿼리, 날짜 함수까지

      1. 격자 BFS 최단 거리

      from collections import deque
def bfs(sr, sc, grid):
    n, m = len(grid), len(grid[0])
    dist = [[-1]*m for _ in range(n)]
    dist[sr][sc] = 0
    q = deque([(sr, sc)])
    while q:
        r, c = q.popleft()
        for dr, dc in ((-1,0),(1,0),(0,-1),(0,1)):
            nr, nc = r+dr, c+dc
            if 0 <= nr < n and 0 <= nc < m \
               and grid[nr][nc] != '#' and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return dist

      5. 다익스트라

      import heapq
def dijkstra(start, adj, n):
    INF = float('inf')
    dist = [INF] * n
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue     # 오래된 항목
        for v, w in adj[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

      6. Union-Find

      parent = list(range(n))
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]   # 경로 압축
        x = parent[x]
    return x
def union(a, b):
    a, b = find(a), find(b)
    if a == b: return False
    parent[b] = a
    return True

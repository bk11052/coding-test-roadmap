      • 시작 10분은 전체 문제를 읽고 푸는 순서를 정합니다

      입력 크기와 시간복잡도

      • N ≤ 10: O(N!) 순열
      • N ≤ 20: O(2ᴺ) 부분집합
      • N ≤ 500: O(N³)
      • N ≤ 5,000: O(N²)
      • N ≤ 10⁶: O(N log N)
      • 그 이상: O(N)
      • 1초에 약 10⁸번 연산 기준. Python은 5~10배 느립니다
